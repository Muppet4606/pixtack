# Security policy

Please report security issues privately using GitHub's **Report a vulnerability** button on the Security tab, rather than opening a public issue.

Pixtack runs entirely locally. It makes no network connections and does not upload anything. Screenshots are only written where you save them, and recordings to `~/Videos/Pixtack`.

Note that the blur tool is not a redaction tool: blurred or pixelated text can sometimes be recovered. Use a filled rectangle to hide sensitive information.
